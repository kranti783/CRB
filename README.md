# Cauvery River Basin – GEE LULC Classification and Validation Data

This repository contains the Google Earth Engine (GEE) scripts and
validation-point shapefiles used for land-use/land-cover (LULC) classification
in the Cauvery River Basin.

## Repository contents

### GEE processing scripts

The following Google Earth Engine JavaScript files contain the LULC processing
scripts:

- `LULC_2000.js` – LULC classification for 2000
- `LULC_2008.js` – LULC classification for 2008
- `LULC_2016.js` – LULC classification for 2016
- `LULC_2024.js` – LULC classification for 2024

### LULC validation data

The following ZIP archives contain the validation-point shapefiles:

- `Cauvery_Validation_Point_Shapefile_2000.zip`
- `Cauvery_Validation_Point_Shapefile_2008.zip`
- `Cauvery_Validation_Point_Shapefile_2016.zip`
- `Cauvery_Validation_Point_Shapefile_2024.zip`
